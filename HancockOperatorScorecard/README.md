# Hancock Operator Scorecard — Power BI custom visual

Full-page personal scorecard for Hancock Iron Ore / Roy Hill weekly operator scorecards
(grader ops, digger ops, dozer ops, coordinators, supervisors, watercarts). One reusable
visual, configured per role entirely from the format pane. Built to the locked spec in
[`SPEC.md`](SPEC.md).

## Deliverable

`dist/hancockOperatorScorecardF1C4A18AEEF940B38A7B91F7861B6D03.1.0.0.0.pbiviz`

**Import:** Power BI Desktop → Visualizations pane → **⋯** → *Import a visual from a file*.
For org-wide rollout, a Fabric admin uploads it to the org visual store instead
(Admin portal → Organizational visuals).

**Known constraint (accepted):** uncertified custom visuals render blank in Power BI email
subscriptions and PDF export. This visual is for on-screen report use; the emailed version
uses the parallel native+Deneb page unless/until certification.

## Field wells (the contract — role keys are permanent)

| Well | Cardinality | Required | Feeds |
|---|---|---|---|
| Person | 1 | yes | grain, rank, quadrant dots, selection |
| Date | 0–1 | no | monthly trend grouping |
| Headline Value | 1 | yes | hero number, rank |
| Focus Person Flag | 1 | yes | 1 = "YOU" (exactly one person) |
| KPI Values | 0–4 | no | KPI tiles, in well order |
| Trend Values | 0–2 | no | trend series (focus person only) |
| Quadrant X / Y | 0–1 each | no | peer scatter |
| Info Values | 0–3 | no | info strip cells 2–4 (text measures OK) |
| Summary Text | 0–1 | no | swing-summary box (plain text) |
| Tooltips | 0–n | no | appended to dot/tile tooltips |

The visual aggregates internally (avg per person over received dates), ranks the focus
person among **whoever arrives** — crew scoping stays outside via page/subscription filters.

## Behaviour notes

- Zero or multiple focus persons → instructive empty state (never throws).
- Missing optional roles → the section auto-hides. All-null measures → "–".
- Rank chip `#n / m`; direction follows Headline → *Higher is better*.
- Quadrant: dashed thresholds (blank = auto at mean), 8 %-opacity quadrant washes,
  peer surname labels cap at 15 peers, focus dot enlarged Deep Blue `NAME · YOU`.
- Cross-filter: quadrant dots only (click / Ctrl-click multi / empty-space clears /
  right-click context menu). Inbound highlights dim non-matching dots to 0.3.
- High-contrast mode honours the host palette (certification-readiness).
- Hero image: `Header → Image URL` accepts `data:` URLs and `https://` URLs
  (https prompts report-level privacy acceptance via the WebAccess privilege).
- Percent-format KPI measures deliver fractions; targets typed as whole percents
  (e.g. `85`) are auto-interpreted as `0.85` against percent-formatted fields.

## fx-enabled properties (ConstantOrRule — drivable from scorecard_config measures)

Every colour and text/target property has the fx button:

- **Header:** Site name, Title, Period label, Image URL
- **Headline:** Label, Units, Target
- **Info strip:** Cell 1–4 labels
- **KPI tiles:** Meeting-target border, Below-target border
- **KPI 1–4:** Label, Units, Target
- **Trend:** Series 1/2 labels, Y min/max, Series 1/2 colours
- **Quadrant:** X/Y thresholds, 4 corner labels, 4 quadrant fills, peer/focus dot colours
- **Summary:** Title, Box colour, Text colour
- **Text:** Font family

Toggles (higher-is-better, section show/hide, invert-Y) and font sizes are constants.

## Development

```bash
npm install
npx pbiviz start                    # dev server (Developer Visual enabled in Desktop)
npx pbiviz package --all-locales    # → dist/*.pbiviz
node test/render_check.mjs          # headless checks against a mock PBI host
```

`--all-locales` is required: the pbiviz 7.x localization loader cannot parse the ESM
locales file in `powerbi-visuals-utils-formattingutils@7`, and the flag bypasses it.

`test/demo_data.csv` (8 persons × 60 days, focus = T. Baker) is regenerated by the test
run for Desktop testing via Get Data → Text/CSV.
